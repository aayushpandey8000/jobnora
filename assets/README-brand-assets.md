# Jobnora brand assets

Brand asset set based on the supplied Jobnora identity board.

- `jobnora-brand-primary.svg`: primary horizontal logo for light backgrounds.
- `jobnora-brand-dark.svg`: horizontal logo lockup for dark backgrounds.
- `jobnora-brand-monochrome.svg`: single-colour lockup.
- `jobnora-app-icon.svg`: app tile.
- `jobnora-favicon.svg`: compact browser/favicon mark.

All SVGs are scalable. The supplied board is a raster reference; these files are clean SVG redraws of the blue/cyan N mark and wordmark, not exact vector tracing of the source artwork.
